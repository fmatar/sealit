# Agentic SDLC Alignment + Proof Kernel Rules (v0.1.0)
_Generated by @fmatar/agentic-sdlc v0.1.0_

## 1. Git Flow & Active Session Guard (INV-01)
- Never commit, merge, or push directly to `main` or `develop`.
- Every commit requires an active session in `.agent/.sdlc-session.json` matching the current branch (`node .agent/scripts/sdlc-engine.mjs begin --checkout --title "<desc>"`).
- Feature, fix, and chore PRs target `develop`; PRs targeting `main` originate exclusively from `develop`.
- Merges into `develop` or `main` require a signed Stage 7 HMAC-SHA256 Gate Receipt in `docs/AUDIT_CHAIN.jsonl`.

## 2. Single-Path Measured Gate & Architecture Rings (INV-02 & INV-04)
- `node .agent/scripts/sdlc-engine.mjs gate` evaluates `docs-only` vs `code` diffs, enforces `.archlens/policy.json` concentric rings, scans diffs for leaked secrets, and measures configured lint, build, test, diff coverage, and diff mutation thresholds.
- All configured commands execute without shell interpolation (`INV-04`).

## 3. Spec & ADR Alignment (INV-03)
- Changes to `PRODUCT.md`, `docs/specs/*`, `.archlens/policy.json`, dependencies, schemas, or API contracts require an accepted ADR (`node .agent/scripts/sdlc-engine.mjs adr create` -> `adr decide --status approve`).

## 4. Canonical Skills Suite (6 Skills)
- `/sdlc`: Direct 1:1 CLI router (`init`, `doctor`, `begin`, `status`, `drift`, `adr`, `test`, `coverage`, `mutation`, `gate`, `review`, `receipt`, `verify`, `end`).
- `/sdlc-spec`: Pure-Markdown specification and `PRODUCT.md` alignment skill.
- `/sdlc-adr`: Spec-drift ADR creation and human approval workflow.
- `/sdlc-tdd`: Red-Green-Refactor TDD and measured diff coverage/mutation runner.
- `/sdlc-gate`: Read-only reviewer subagent dispatch, `sdlc gate`, and signed Stage 7 receipt.
- `/sdlc-flow`: End-to-end branch delivery orchestrator (`begin -> align -> tdd -> gate -> receipt -> end`).
