# SDLC TDD & Clean Code Implementation Skill (`sdlc-tdd-implement`)

Use this skill when implementing new features, components, math modules, audio engines, or refactoring existing code in NoteZen.

---

## 💎 Core Engineering Standards

### 1. Svelte 5 Runes & Reactivity
- **State Declaration**: Always use `$state()` for reactive variables and objects.
- **Derived Values**: Always use `$derived()` or `$derived.by(() => ...)` for computed values. Never synchronize state manually with watch loops.
- **Side Effects**: Use `$effect()` exclusively for DOM manipulation, `AudioContext` trigger hooks, and `requestAnimationFrame` lifecycles. Ensure clean teardown/cleanup functions are returned.
- **Props**: Use `$props()` with strict TypeScript interfaces.

```svelte
<script lang="ts">
  interface Props {
    techniqueId: string;
    isActive?: boolean;
    onComplete?: () => void;
  }

  let { techniqueId, isActive = false, onComplete }: Props = $props();
  let cycleCount = $state<number>(0);
  let progress = $derived<number>(cycleCount > 0 ? cycleCount / 10 : 0);
</script>
```

### 2. Strict TypeScript & Typing Discipline
- Strict type-checking with zero `any` or loose `as unknown` casts.
- Co-locate domain types in `src/lib/types/` or export them cleanly from data definitions (`src/lib/data/techniques.ts`).
- Exhaustive pattern matching across union types (e.g. technique IDs, theme modes, breath phase types).

### 3. SVG & Math Geometry Principles
- Keep geometric generators purely mathematical and deterministic (no state mutation inside math helpers).
- Support dynamic container scaling (`viewBox` coordinate normalization).
- Ensure smooth interpolation between polygon vertices or Bézier curves for 60fps focal dot animation.

### 4. Web Audio Synthesis Best Practices
- Never use pre-recorded MP3/WAV files for core chimes — synthesize tones programmatically via `AudioContext`, `OscillatorNode`, `GainNode`, and `BiquadFilterNode`.
- Prevent audio pops/clicks: Always use `exponentialRampToValueAtTime` or `linearRampToValueAtTime` for volume envelopes instead of instant jumps.
- Clean up memory: Disconnect gain nodes and stop oscillators when audio events terminate.

## 🛠️ Step-by-Step Implementation Workflow

1. **Review Specification**: Load the RFC / Issue generated by `sdlc-feature-spec`.
2. **Write Failing Tests First (TDD)**:
   - For math/geometry modules: Create unit tests in `src/lib/geometry/*.test.ts` verifying coordinates, path lengths, and bounding boxes.
   - For stores: Create state tests in `src/lib/stores/*.test.ts` verifying phase transitions and timing.
3. **Implement Minimum Viable Code**:
   - Implement data types and definitions.
   - Implement math generators and algorithms.
   - Wire up Svelte 5 components and CSS styling.
4. **Refactor & Optimize**:
   - Strip dead code, optimize rendering passes, and verify micro-animations.
5. **Verify with Type-Checker**:
   - Run `npx svelte-check --tsconfig ./tsconfig.json` to guarantee TypeScript and Svelte 5 compilation validity.
