# SDLC TDD & Clean Code Implementation Skill (`sdlc-tdd-implement`)

Use this skill when implementing new features, backend services, UI components, or refactoring existing code across full-stack applications.

---

## 💎 Core Engineering Standards

### 1. Svelte 5 Runes & Reactivity (Frontend)
- **State Declaration**: Always use `$state()` for reactive variables and collections.
- **Derived Values**: Always use `$derived()` or `$derived.by(() => ...)` for computed values. Never manually synchronize state with loops or watchers.
- **Side Effects**: Use `$effect()` exclusively for DOM manipulation, canvas updates, or subscription lifecycles. Ensure teardown/cleanup functions are returned.
- **Props**: Use `$props()` with strict TypeScript interfaces.

```svelte
<script lang="ts">
  interface Props {
    itemId: string;
    isActive?: boolean;
    onSelect?: (id: string) => void;
  }

  let { itemId, isActive = false, onSelect }: Props = $props();
  let interactionCount = $state<number>(0);
  let isHighlighted = $derived<boolean>(isActive && interactionCount > 0);

  function handleClick() {
    interactionCount++;
    onSelect?.(itemId);
  }
</script>

<button class="btn" class:active={isHighlighted} onclick={handleClick}>
  <slot />
</button>
```

### 2. Quarkus & Java 25 Standards (Backend)
- **Modern Syntax**: Use Java 25 language features (records, sealed classes, pattern matching, virtual threads).
- **Reactive Streams**: Use Mutiny (`Uni<T>`, `Multi<T>`) for asynchronous, non-blocking I/O.
- **Data Access**: Use Hibernate Reactive with Panache (`PanacheEntityBase` or `PanacheRepositoryBase`). Never perform blocking operations on event loops.
- **Idempotency & Concurrency**: Enforce idempotent event processing and safe concurrency boundaries.

```java
@ApplicationScoped
public class TaskService {

    @WithTransaction
    public Uni<TaskDto> completeTask(UUID taskId, UserPrincipal principal) {
        return TaskEntity.<TaskEntity>findById(taskId)
            .onItem().ifNull().failWith(() -> new NotFoundException("Task not found"))
            .flatMap(task -> {
                task.completed = true;
                task.completedAt = Instant.now();
                return task.persistAndFlush();
            })
            .map(TaskDto::from);
    }
}
```

## 🛠️ Step-by-Step TDD Workflow

1. **Review Specification Contract**: Load the RFC / Issue generated by `sdlc-feature-spec`.
2. **Write Failing Tests First (TDD)**:
   - Frontend: Unit tests in `src/lib/**/*.test.ts`.
   - Backend: Unit & integration tests in `src/test/java/**/`.
3. **Implement Minimum Viable Code**:
   - Create models, entities, and data transfer objects.
   - Implement business logic, reactive stores, or service layer.
   - Wire up UI components and endpoints.
4. **Refactor & Type Check**:
   - Run `npx svelte-check --tsconfig ./tsconfig.json` for frontend type safety.
   - Run `./mvnw compile` for backend compilation.
