# CAP-06: Canonical 6-Skill Suite, Symlink-Safe Multi-Agent Installer & Doctor

- **Capability ID**: `CAP-06`
- **Governing Module**: `.agent/scripts/lib/install.mjs` (Ring 2), `.agent/skills/{sdlc,sdlc-spec,sdlc-adr,sdlc-tdd,sdlc-gate,sdlc-flow}/SKILL.md`
- **Enforced Invariants**: `INV-01`, `INV-02`, `INV-04`

## 1. Inputs
- Canonical skill sources in `.agent/skills/<id>/SKILL.md`, target project directory (or `--global` `$HOME`), and selected AI coding agents (`antigravity`, `claude`, `cursor`, `codex`, `copilot`).

## 2. Domain Rules
1. **Single Tracked Skill Source, Harness Neutrality & Plugin Parity**: Only `.agent/skills/{sdlc,sdlc-spec,sdlc-adr,sdlc-tdd,sdlc-gate,sdlc-flow}/{SKILL.md,agents/openai.yaml}` are tracked in git; `.claude-plugin/plugin.json` lists all 6 canonical skill directories as an explicit array matching `package.json` version. Canonical `SKILL.md` files omit non-standard `tools:` frontmatter, use harness-neutral subagent phrasing, and include a `.agent/sdlc-config.json` kernel check (`sdlc-spec`, `sdlc-adr`, `sdlc-tdd` run standalone with native repo tools without claiming kernel measurements; `sdlc-gate` and `sdlc-flow` stop and offer `/sdlc init`; `sdlc` bootstraps `init`/`doctor` via `npx --yes github:fmatar/agentic-sdlc-framework`). `sdlc` sets `disable-model-invocation: true` (`allow_implicit_invocation: false`), while the 5 workflow skills remain model-invocable. Local installer targets map `claude` and `copilot` to `.claude/skills`, `cursor` to `.cursor/skills`, and `codex` to `.codex/skills` (deduplicated), while `--global` `antigravity` targets `~/.gemini/config/skills` and prunes legacy `~/.gemini/antigravity/skills/sdlc*`.
2. **Strict `sdlc*` Namespace Isolation, `npx skills` Coexistence & Retirement Pruning**: `installFramework` prunes retired `sdlc-*` skills (`sdlc-doctor`, `sdlc-product`, `sdlc-release`, `sdlc-status`, `sdlc-wiki`) and legacy duplicate `.cursor/rules/sdlc*.mdc` files while leaving all non-`sdlc*` user skills untouched. When `.agents/skills/<id>/SKILL.md` exists (`vercel-labs/skills`), local `installFramework` skips overwriting `<id>` in agent target directories and emits warnings (including a duplicate-listing notice for `.agent/skills` vs `.agents/skills`).
3. **Symlink-Safe Provisioning, Layout-Aware Scaffolding & First-Adoption Key**: All file/directory writes unlink pre-existing symlinks (`lstatSync().isSymbolicLink()`) before writing so symlinks cannot redirect writes outside the target workspace. Valid `.agent/sdlc-config.json` files, malformed `.claude/settings.json` files, and user-curated `permissions.allow` lists are preserved without data loss, while hook-only or `--force` `.claude/settings.json` files merge `CLAUDE_SDLC_ALLOW_RULES` without clobbering `hooks` or custom settings. Managed `.gitignore` entries include `coverage/` and `reports/`. `scaffoldArchlensPolicy` emits the 4-ring `src/{domain,application,adapters,entrypoints}` policy only when at least one of those ring directories exists, otherwise scaffolding an empty-ring policy (`levels: []`, `order: []`, `.agent` omitted) matching `src/` or `.`. Local `sdlc init` provisions an untracked `0600` `.agent/.receipt-key` exclusively on first adoption (`.git` present, no prior `.agent/sdlc-config.json`, zero gate receipts in `docs/AUDIT_CHAIN.jsonl`, and no env/`.env`/file key configured).
4. **Read-Only Doctor & Skill Audit**: `runDoctor({ fix: false })` and `auditSkills` inspect runtime, git, config schema, `.archlens/policy.json`, hook SHA-256 digests, CI workflow freshness, `.agent/.receipt-key` status + `gh secret set SDLC_RECEIPT_KEY` hint (emitted only when a usable `.agent/.receipt-key` file exists), skill frontmatter/line caps (`<= 160` lines), `agents/openai.yaml` invocation parity, `.claude-plugin/plugin.json` version/skills parity, and `AUDIT_CHAIN.jsonl` integrity without mutating disk or `process.env`.

## 3. Outputs & Acceptance Criteria
- `sdlc skill-audit` passes all 6 canonical skills with `0` findings.
- `sdlc init --yes` and `sdlc doctor --fix` provision or upgrade local/global installations deterministically; `npm pack --dry-run` produces a `< 120 kB` tarball with zero runtime dependencies.
