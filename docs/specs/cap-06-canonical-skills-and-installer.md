# CAP-06: Canonical 6-Skill Suite, Symlink-Safe Multi-Agent Installer & Doctor

- **Capability ID**: `CAP-06`
- **Governing Module**: `.agent/scripts/lib/install.mjs` (Ring 2), `.agent/skills/{sealit,sealit-spec,sealit-adr,sealit-tdd,sealit-gate,sealit-flow}/SKILL.md`
- **Enforced Invariants**: `INV-01`, `INV-02`, `INV-04`

## 1. Inputs
- Canonical skill sources in `.agent/skills/<id>/SKILL.md`, target project directory (or `--global` `$HOME`), and selected AI coding agents (`antigravity`, `claude`, `cursor`, `codex`, `copilot`).

## 2. Domain Rules
1. **Single Tracked Skill Source, Harness Neutrality & Plugin Parity**: Only `.agent/skills/{sealit,sealit-spec,sealit-adr,sealit-tdd,sealit-gate,sealit-flow}/{SKILL.md,agents/openai.yaml}` are tracked in git; `.claude-plugin/plugin.json` lists all 6 canonical skill directories as an explicit array matching `package.json` version. Canonical `SKILL.md` files omit non-standard `tools:` frontmatter, use harness-neutral subagent phrasing, and include a `.agent/sealit-config.json` kernel check (`sealit-spec`, `sealit-adr`, `sealit-tdd` run standalone with native repo tools without claiming kernel measurements; `sealit-gate` and `sealit-flow` stop and offer `/sealit init`; `sealit` bootstraps `init`/`doctor` via `npx --yes @sealit/cli` (or `npx --yes github:fmatar/sealit`)). `sealit` sets `disable-model-invocation: true` (`allow_implicit_invocation: false`), while the 5 workflow skills remain model-invocable. Local installer targets map `claude` and `copilot` to `.claude/skills`, `cursor` to `.cursor/skills`, and `codex` to `.codex/skills` (deduplicated), while `--global` `antigravity` targets `~/.gemini/config/skills` and prunes legacy `~/.gemini/antigravity/skills/{sealit*,sdlc*}`.
2. **Strict `sealit*` Namespace Isolation, `npx skills` Coexistence & Retirement Pruning**: `installFramework` prunes retired `sdlc*` skills (`sdlc`, `sdlc-spec`, `sdlc-adr`, `sdlc-tdd`, `sdlc-gate`, `sdlc-flow`, `sdlc-doctor`, `sdlc-product`, `sdlc-release`, `sdlc-status`, `sdlc-wiki`) and legacy `.cursor/rules/{sealit,sdlc,agentic-sdlc}*.mdc` files while leaving all unrelated user skills untouched. When `.agents/skills/<id>/SKILL.md` exists locally or in `$HOME` (`vercel-labs/skills`), `installFramework` skips overwriting `<id>` in agent target directories and emits warnings (including a duplicate-listing notice for `.agent/skills` vs `.agents/skills`).
3. **Symlink-Safe Provisioning, Claude Deny Friction, Single-Pass Trusted CI & First-Adoption Key (`ADR-028`)**: All file/directory writes unlink pre-existing symlinks (`lstatSync().isSymbolicLink()`) before writing so symlinks cannot redirect writes outside the target workspace. Valid `.agent/sealit-config.json` files, malformed `.claude/settings.json` files, and user-curated `permissions.allow` lists are preserved without data loss, while fresh, legacy-migrated, or `--force` `.claude/settings.json` files merge `CLAUDE_SEALIT_ALLOW_RULES` and `CLAUDE_SEALIT_DENY_RULES` (protecting `.agent/.receipt-key` and `.agent/.sealit-session.json` from accidental agent edits) without clobbering `hooks` or custom settings. `buildQualityGateWorkflow` emits single-pass env-isolated CI (`SEALIT_RECEIPT_KEY: ci-dummy-test-key` on the gate step, omitting duplicate `npm test`), supports `SSHSIG` base-branch `.agent/allowed_signers`, emits the `fmatar/sealit` self-hosted runner guard only for the owner repository, and executes consumer PR `config check`, `verify --chain-only`, `skill-audit`, and `gate --no-cache` via a freshly extracted `origin/$BASE_REF` trusted engine after `npm ci`. Managed `.gitignore` entries include `coverage/` and `reports/`. `scaffoldArchlensPolicy` emits the 4-ring `src/{domain,application,adapters,entrypoints}` policy only when at least one of those ring directories exists, otherwise scaffolding an empty-ring policy (`levels: []`, `order: []`, `.agent` omitted) matching `src/` or `.`. Local `sealit init` provisions an untracked `0600` `.agent/.receipt-key` exclusively on first adoption (`.git` present, no prior config, zero gate receipts in `docs/AUDIT_CHAIN.jsonl`, and no env/`.env`/file key configured).
4. **Read-Only Doctor & Skill Audit**: `runDoctor({ fix: false })` and `auditSkills` inspect runtime, git, config schema, `.archlens/policy.json`, hook SHA-256 digests, CI workflow freshness, `.agent/.receipt-key` status + `gh secret set SEALIT_RECEIPT_KEY` hint (emitted only when a usable `.agent/.receipt-key` file exists), skill frontmatter/line caps (`<= 160` lines), `agents/openai.yaml` invocation parity, `.claude-plugin/plugin.json` version/skills parity, and `AUDIT_CHAIN.jsonl` integrity without mutating disk or `process.env`.

## 3. Outputs & Acceptance Criteria
- `sealit skill-audit` passes all 6 canonical skills with `0` findings.
- `sealit init --yes` and `sealit doctor --fix` provision or upgrade local/global installations deterministically; `npm pack --dry-run` produces a `< 120 kB` tarball with zero runtime dependencies.
